
# Core PHP Employee Management System

A practice CRUD application built using Core PHP and MySQL.

## Features
- Create employees
- View employee records
- Update employee details
- Delete employee records
- PDO database connection
- Prepared statements
- Input validation
- HTML output escaping
- CSRF protection for forms

## Technologies
- PHP
- MySQL
- PDO
- HTML

## Setup Instructions
1. Install XAMPP and start Apache and MySQL.
2. Copy the project into the htdocs folder.
3. Import database.sql using phpMyAdmin.
4. Check config/database.php for local database settings.
5. Open http://localhost/php-crud-practice/.

## Purpose
Created for learning and practising Core PHP,
MySQL, CRUD operations, and secure database queries.
